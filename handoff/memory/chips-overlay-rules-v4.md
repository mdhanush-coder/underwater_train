User review of section 2 v4 (2026-11-12), building on the reference style board (dark glossy set, warm bokeh, gold rim, chip right of centre):
- KEEP: the header (gold dash + "02 — THE BRAIN", letter-spaced topic right) and the two-tone headline/subline text style.
- REMOVE: the 1-2-3-4 step strip at the bottom; icons inside callout cards; the "3D ILLUSTRATION" tag.
- Callout tags appear only when the narrator says that part (word-timed, not all at once with the line).
- Everything was too big and hid the model: compact cards (title + one line), smaller default headline; use the big headline only when the frame has a large empty area so the model stays clearly visible.
- Headline position is NOT fixed to top-left: put it wherever the frame has dark empty space (left/right, top/bottom), chosen per shot so the model stays clear (2026-11-12).
- Bokeh bulbs (Blender spheres and the drifting overlay ones) a little lower in opacity than the first pass.
**Why:** text was covering the 3D and the extras read as clutter.
**How to apply:** every section of this video and later XU explainers in this theme. Related: [[chips-brahmos-presentation-style]], [[xu-no-plain-backgrounds-no-text-over-models]].
