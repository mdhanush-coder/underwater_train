User rejected the first chips overlay (2026-11-12): handwritten Kalam notes beside a plate in a visible rectangle "not looking good".
Wanted "professional stylish texts and the presentation like the BrahMos" (projects/brahmos/overlays/overlay_ch1.html).
Recipe now: full-frame 3D plate (pushed right, soft left fade, never a box edge), Unbounded 800-900 for titles and big numbers,
Rajdhani 600 for lines (>= 48 px), JetBrains Mono 30 px HUD labels (letter-spacing .12em), "3D ILLUSTRATION" note top left,
one gold item per frame, entrances rise 24 px 0.5 s power3.out, exits 0.4 s.
**Why:** handwriting read amateur for a defence/tech explainer; BrahMos look was already approved.
**How to apply:** default for XU tech explainers unless the user asks for the annotated-photo look ([[gaganyaan-annotation-look-approved]] is for photo annotations only). Related: [[brahmos-no-text-boxes]], [[brahmos-palette-charcoal-gold]].
