User (2026-11-12, missile-chips video): "the transitions should feel like butter, do not do hard cuts".
**Why:** hard cuts between 3D plates read as jumpy, unprofessional.
**How to apply:** inside a section, every plate change is a soft dissolve (~0.8-1.0 s, eased, clips overlap) or a camera move that hands off; text exits before the dissolve; between sections the assembly crossfades too (no butt joins). Never a frame-to-frame jump to a new view of the same subject. Related: [[chips-overlay-rules-v4]].
